# Núcleo de Génesis DIG

Este paquete contiene la implementación inicial del motor reutilizable: representación de estados, reglas de interacción, selección aleatoria de posibilidades y registro de eventos.

**Estado:** implementación mínima disponible en `motor.py`, cubierta por pruebas unitarias. Es una base de ingeniería para experimentos abstractos, no un modelo físico completo.

No incorporar supuestos físicos ni reglas destinadas a producir de antemano un resultado concreto.

Autoría del proyecto: José María Pérez Rodríguez (JMPR).
