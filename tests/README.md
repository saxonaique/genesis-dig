# Pruebas

Aquí se añadirán pruebas automáticas para comprobar reglas, reproducibilidad y comportamiento esperado del código.

Las pruebas deberán distinguir entre comprobar que el programa funciona como se diseñó y demostrar una hipótesis científica: son cosas diferentes.
