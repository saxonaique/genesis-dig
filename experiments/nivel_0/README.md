# Experimentos del Nivel 0

Cada experimento tendrá una carpeta o conjunto de archivos propio, con objetivo, hipótesis operativas, parámetros, semilla aleatoria, procedimiento, controles y resultados.

E001 comprueba técnicamente el motor con reglas explícitas. E002 explora la persistencia temporal en tablas deterministas y cuenta con resultados reproducibles. Ambos son modelos abstractos y no validan DIG.

**Estado:** E001 y E002 están implementados y ejecutados; la auditoría de E002 se completó el 2026-10-19. La revisión del material histórico 001–005 y el diseño de experimentos posteriores siguen pendientes; no se ha iniciado E003.
